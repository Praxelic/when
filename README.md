# `when`

> A simple tool that extracts YouTube video ID(s) and upload dates from URL(s) and displays them in a terminal output.

---

## Usage

```bash
when "<url>"
```

---

## Output Example

```text
                                       ┌────────────────────────────────────────┐
                                       │             Video ID: (ID)             │
                                       │   Upload Date: 000-00-00 00:00:00 UTC  │
                                       └────────────────────────────────────────┘
```

<center>
Output is centered in the terminal.
</center>
